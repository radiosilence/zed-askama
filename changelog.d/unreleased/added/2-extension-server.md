- **The Zed extension starts askama-analyzer and gives it a rust-analyzer.** It uses the binary set in `lsp.askama-analyzer.binary`, then one on `PATH`, then downloads the latest release for the platform and keeps it current, falling back to the last download when offline; rust-analyzer is found the same way, from Zed's own `lsp.rust-analyzer` settings, and those settings are passed to the server.
