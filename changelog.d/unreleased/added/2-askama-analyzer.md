- **Askama templates get completion, navigation and errors in Zed.** Askama turns a template into Rust inside a derive macro, so rust-analyzer could only report a broken template as an error on the struct. The new Zed extension highlights templates with a grammar of its own and runs `askama-analyzer`, which feeds askama's generated code to the user's rust-analyzer and maps completion, hover, definitions, references, renames and errors back to the template.
